# AI Text Analyzer

Analyse, corrige, reformule et résume du texte avec une IA locale (Ollama).

## Stack

- Backend : Node.js + Express + TypeScript
- Frontend : Angular 18
- IA : Ollama (llama3.2:1b)

## Installation

```bash
git clone https://github.com/SabriRh/text-analyzer
cd text-analyzer

# Backend
cd backend
npm install
npm run dev

# Frontend
cd frontend
npm install
ng serve
